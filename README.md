# Zoe’s Apartment Warming 🏠

A small digital card I made for my friend Zoe to celebrate her moving into a new apartment.

I started this project from one of my previous housewarming repos and reworked it for Zoe, changing the visuals, copy and details to make it feel personal to her and her new place.

### [View the live website →](https://vivil10n.github.io/zoes-apartment-warming/)

## Built with

* HTML
* CSS
* JavaScript
* GitHub Pages

## About the design

I wanted it to feel like a tiny housewarming gift that lived on the internet. Cute ASCII, a personal note and a small page to mark the occasion.

Designed and built by [Vivian Truong](https://www.vivitruon.com/) for Zoe and her new home.
